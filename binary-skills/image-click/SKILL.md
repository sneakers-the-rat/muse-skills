# Image click

One picture asks for a point or an object in it. Pages say things like "Select the odd one out", "Pick the object that is the mirror image of the one on the left", "Click the item that matches the reference" or "Click where the line breaks".

- Read the question exactly, including negations such as "not" and the reference picture, and answer the question asked, not a familiar variant.
- Describe the answer by what it shows and where it sits in the picture, with the widget's reference in `within`, and click it once. When the question asks for more than one, such as the two shortest towers, name them all in the same click.
- Look for a round counter, such as "1 of 5". Each round is new, so finish every one.
- A rejected answer usually brings a new picture. Look again rather than clicking the same place.
- After the last round, check the page; a completion animation does not prove the page is usable.
