# Icon order

Icons must be clicked in a stated order. Pages say things like "Click the icons in the following order" or "Please click in order", with a strip of small icons beside the picture.

- Read the order from the instruction or the strip of small icons, from left to right.
- Find each icon in the large picture. It can be turned, recoloured or a different size.
- Click each one in turn, in the stated order, describing it in `look` with the widget's reference in `within`.
- Before you confirm, check that each icon you clicked shows its number or mark, in order. When one is missing or sits on the wrong icon, use the widget's reset or refresh control rather than carrying on.
- Then press the widget's confirm button by its reference when it has one. A confirm described in `look` can land on the picture as one more click.
