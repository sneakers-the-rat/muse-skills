# Arithmetic and counting

A question asks for a sum, a count of objects or the value shown on dice. Pages say things like "What is 7 + 3?", "How many dogs are in the picture?" or "Pick the image where the dice add up to 14".

- Answer the question actually asked, not a familiar variant: the total, the number of one kind of object or the result shown.
- Count from the current screenshot one object at a time, and count once more before you answer.
- Type the number into the challenge's field or click the matching choice, and check it before you submit.
- Each round brings a new picture, so count it afresh.
