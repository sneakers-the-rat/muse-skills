## Classification and routing

Classify each input once, using its applicable content guidance. Use the
assignment's suppression result when it does not merit consideration. The runtime
routes results through the active selection and delivery flow; an urgency label
never sends a message by itself. Use urgent only when the classification mode
permits it and the evidence supports an immediate interruption. Do not lower the
bar on the assumption that a later research pass will repair weak evidence.
The composer cannot change the classification. Classification is not proof of delivery: consult
actual delivery outcomes before repeating information.
