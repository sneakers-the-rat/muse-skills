# Translation

## Understand the use

- Establish the target language and, when it changes the result, the region, audience and purpose. Portuguese for Brazil differs from Portuguese for Portugal, and Spanish for Mexico differs from Spanish for Spain.

- Use the context to settle tone and ambiguous phrases. Ask about an ambiguity only when a silent choice could change the meaning.

## Preserve what matters

- Translate the meaning into natural language for the reader. Keep names, numbers, dates, units, links and product identifiers accurate.

- Follow the user's glossary and keep terms consistent across the document. For specialized work, prefer the organization's own published terminology.

- Preserve useful headings, tables and formatting. For a document, check the exported file as well as the text.

- When legal, medical or technical wording has several plausible meanings, explain the uncertainty and keep the original term beside the translation where it helps.

- Keep a faithful translation separate from any adaptation or rewrite the user asked for. Never present an ordinary translation as certified.

## Check the result

- Compare the translation with the original for omissions, changed meaning and inconsistent terms. Read it once as the intended reader would.

- Deliver the translated text or file with only the notes needed to explain a material choice or an uncertainty.

## Websites

- [DeepL Translator](https://www.deepl.com/translator) when the DeepL connector is not available in this session. It translates text without a connected account.

- [Google Translate](https://translate.google.com/) for a second rendering of a difficult phrase and for languages DeepL does not cover.

- [Linguee](https://www.linguee.com/) for bilingual example sentences that show how a term is used in context.

- [IATE](https://iate.europa.eu/) for European Union terminology and [TERMIUM Plus](https://www.btb.termiumplus.gc.ca/) for Canadian English and French terminology.

- Send a browser task only text the user is comfortable sharing with that service, and have it return the rendering and where it came from.

## Alternatives for better results

- Translate a short passage directly. When a phrase is difficult, compare a second rendering on meaning rather than on fluency.

- For an official filing that requires certification, recommend a certified or sworn translator accepted by the recipient, such as the court or embassy.
