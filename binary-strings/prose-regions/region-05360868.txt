 Server-curated catalog selector for `GET /connectors`. An unknown value is a
 deserialization error → `400`. Select the server-curated connector catalog for the calling surface. Page size (1..=100). Supplying any of `limit`, `cursor`, `category`,
 or `q` selects paged marketplace mode (settings surface only);
 otherwise the full catalog is returned. Defaults to the cursor's page
 size, else 20; when supplied with a `cursor`, overrides it. Opaque `next_cursor` from a previous paged response; blank is ignored.
 Carries the category and `q`, so those parameters are ignored when it
 is supplied. A stale cursor returns `400` with code `cursor_expired`. Restrict to a marketplace category. Selects paged mode. Comma-separated connect flows this client can run, using the
 `connect/info` `action.type` vocabulary (`oauth`, `api_key`,
 `consent_only`, `messenger`, `whatsapp`, `foa_auth`, `none`), e.g.
 `supports=oauth,consent_only`. A disconnected row whose Connect button
 would run an undeclared flow is omitted; a row the person has already
 connected is always kept, because that row is also how they inspect its
 permissions and disconnect it. `custom.*` rows are always kept, since
 they carry no classifiable flow. Omitting the parameter applies no
 filter, so every existing client keeps today's catalog, and an
 unrecognized token matches no row rather than failing the request.
 Refused with `400` in paged mode, where the cursor does not carry it. Comma-separated additive capability tokens. `credential_forms_v1`
 declares the caller can render server-defined credential forms.

 query matches anywhere in the name. At most 200 characters after
 trimming; blank is ignored. Selects paged mode. Without a category,
 searches every visible connector. Canonical connector id / slug (e.g. `gmail`, `outlook_mail`,
 `custom.foo`). The connectors: the whole catalog in legacy mode, or one page in paged
 mode (any of `limit`, `cursor`, `category`, or `q` supplied). Paged mode only: the selected category's id and localized title;
 present iff a category was requested (directly or via the cursor). Paged mode only: up to three featured connectors, the most popular
 disconnected connectors in the category, in popularity order.
 `needs_reauth` and `coming_soon` never appear, and on a confidential VM
 neither do connectors whose data is visible to Meta. Present,
 possibly empty, on the first page of a `productivity`, `social`,
 `health`, `business`, or a configured category without `q`; absent otherwise,
 including `wallet`.
 Featured IDs are excluded from `connectors` throughout that cursor's
 pagination chain. Paged mode only: opaque cursor for the next page; absent on the last
 page. Set only on the task a tapped feed card put first, whether for the
 card's Idea or its prompt: the app the card was on. Absent when the app
 isn't known. App of the feed card that put a task first. Stable identifier scoped to the containing task. Whether the group accepts one connector or multiple connectors. Required groups must be satisfied before the task can run. Optional
 groups provide additional context when connected. Canonical connector ids (connector slugs). Exactly one connector when required; zero or one when optional.
