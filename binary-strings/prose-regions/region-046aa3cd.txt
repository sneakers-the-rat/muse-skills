chat.listList the user's Muse chats. It returns one entry per chat with its chat_id UUID, its name, whether it's the Main chat, archived and pinned flags, and status. A chat connected to an external messaging service also includes `provider`, naming that service. A group chat on a messaging service is named after its room and includes `group`, which holds the room's name, the display names of the people in it, and when its latest message was sent. People in the room set these names. By default it returns only active chats. Set include_archived to true to see archived ones too. Use the returned chat_id with chat.read_messages, chat.send_message, chat.rename, chat.archive, or chat.delete.

chat.send_messageSend an instruction to another chat, using its `chat_id` from `chat.list`.

- For a native chat, that chat's agent gets the instruction and responds in that chat.
- For a group chat, the group's worker gets it as a private task. The worker handles the group conversation and sends questions and results for the user back to this chat privately, or to the main chat when this chat is on a messaging service.

Direct messaging-service chats without a worker can't receive these instructions.

The call returns right away with `submission_message_id`. This receipt doesn't confirm delivery or completion.

chat.read_messagesRead messages from an existing chat to catch up on that conversation before you answer or route work. chat_id is the UUID that chat.list returns, including for the Main chat, or the hidden group-chat UUID supplied in an authorized handoff. It returns full conversation turns, newest first, and each turn carries messages with role, content, and timestamps. In group chats, participant messages also carry group_message sender and reply metadata, and assistant messages are the worker's replies in the room. Group transcripts leave out private worker handoffs. limit caps the turns per call (default 5, maximum 20). Pass next_cursor as cursor to read the next older page. Reading doesn't change the chat.
