Visual grounding tool that locates, labels, or counts objects in an image, returning coordinates. Use it when the answer needs exact positions or counts; answer plain questions about an image you can already see directly, without this tool. Treat the returned results as authoritative and report them directly; do not re-run the tool to change a result that looks surprising. For a complex ask, make a few focused calls in parallel rather than one broad one; targeted asks return better results.

Coordinates are normalized to the exact file passed as image_path. If you crop or zoom an image, run the tool again on the new file instead of transforming earlier coordinates; numbers measured on the original will not line up on a crop.

When the user wants the results shown on the image, build an annotated HTML file with muse.exec, embedding the image as a base64 data URI with the markers drawn over it; otherwise report them in text. Keep the <img> and its overlays in one padding-free position:relative wrapper sized exactly to the image, so the markers line up. In any JavaScript, embed the image as a base64 variable rather than a sandbox:// URL, which is a display reference, not a file path.
