task in the existing user browser process, presents it and acquires user control without starting an agent. New leases return control_owner=user; use the existing viewer and heartbeat APIs. Optional viewer width/height are client physical pixels; device_pixel_ratio defaults to 1 and derives the logical framebuffer size, with a proportional 500-pixel minimum width and native bounds. A retry without viewer metadata preserves its current preference; explicit metadata updates the currently presented lease without renewing control. Pass it to the existing browser client and use browser_task_id with the present, viewer, takeover, heartbeat, release and stop APIs. Supply a UUID lease_id and retain it for retries; an ended lease returns 410. Closing the viewer keeps the lease; stop releases it.
