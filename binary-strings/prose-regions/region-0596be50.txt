Supplying any of `limit`, `cursor`, `category`, or `q` selects paged marketplace mode (settings surface only; blank `cursor` and `q` are ignored): `category` and `q` (at most 200 characters) select and filter the result set, the page size defaults to 20. Search matches case-insensitive substrings in rendered names while preserving the existing order. The response adds `category`, first-page `featured` (for configured categories or bundled `productivity`, `social`, `health`, and `business` without `q`) and `next_cursor`. Featured rows are excluded from the regular connector pages throughout the cursor chain. Published configuration resolves category IDs, localized titles, membership, and ranking by account country. Bundled defaults use manifest membership and ordering.yaml ranks. Verified connectors without a manifest category are excluded from global unfiltered browsing, but remain in global search. Search excludes stripe-link and shop-pay; Connected also excludes them for the separate Wallet tab, even when their manifest category is absent. Connected also lists the companies Muse is signed in to through the Personal Agent Protocol (`group: optimized_sites`). `category=wallet` lists Link by Stripe followed by Shop Pay, with the same visibility, localization, and coming-soon rules when browsed without `q`. Wallet loads provider state only for the selected page, uses no custom source, and has no Featured or homepage preview. Both wallets remain in the legacy unpaged list. A cursor minted under another config/country revision or locale, or whose anchor left the result set, returns `400` with code `cursor_expired`. Required custom lookup failures return `500` in paged mode; only the legacy unpaged list omits custom rows on failure.
