Read the current page in a tab.

Tool calls from this browser agent execute sequentially in their listed order, including calls on different tabs and inspections of saved images. For a decision that depends on an action's outcome, wait for that result before choosing the next action.

`auto` returns the page's content with references to its controls, `text` returns the page's prose, and `element` returns the requested `fields` of the element named in `ref`. Each view comes with a screenshot of the page. Each screenshot shows the page at the moment of that result. A `query` returns only the matching lines of the `auto` or `text` view.

For small details, add `image` with a `crop` rectangle (`x`, `y`, `width`, `height`) in full screenshot pixels and an optional `scale`, such as 2 to enlarge it. The result attaches the full screenshot first, followed by the inspection copy, with the same password masks. This changes the image only, not page zoom or layout. Cropping does not add missing detail; it makes the selected region easier to inspect.

The result reports the actual crop and output dimensions. For a point `(u, v)` in the inspection copy, its full screenshot coordinates are `x = crop.x + u * crop.width / width` and `y = crop.y + v * crop.height / height`. Use the reported dimensions because normal image delivery limits can reduce the requested scale. Ordinary actions still use `ref` or `look`; pixel programs compute coordinates in their own fresh `frame`, whose dimensions can differ. Do not copy coordinates from a resized image into a program unchanged.

To inspect exact saved pixels, set `image.source` to `{"screenshot":"i12"}`, using the screenshot reference. For a program capture, use `{"receipt":"r4","program":1,"frame":2}`: the receipt is from the action result, programs are numbered from 1 within that result, and frame indices are reported by the program. Only retained frames can be selected. Use exactly one source form; do not mix its fields with another form. A retained inspection does not refresh the page or replace its current action references. Do not combine it with a text query, element inspection or listening request.

Annotations need no code but require `image.source`, using a saved screenshot reference or a retained program frame.
