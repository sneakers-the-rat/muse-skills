voice_fast_ui_navigationvoice_fast_set_voice/action.mdUse this fast action only when the caller's entire latest request unambiguously selects one target available voice and asks only to switch to it. The target may be a catalog voice, a saved voice in Your Voices, or one saved voice's profile label. Copy the selected target even if another available voice name appears as context: “Bloom sounds good, but switch back to Warm” selects `Warm`, and “switch from Warm to Bloom” selects `Bloom`. This also includes a short committed choice such as “let's go with Rich.” Hard exclusion: if that same request asks for any other action or information, use `other` even when it contains an exact voice name. For example, “switch to Smoky and tell me tomorrow's weather” is `other`, never `set_voice`. A reference is not a name: never use this action for “switch back,” “the previous voice,” “the old voice,” “the second one,” a pronoun, or an ordinal unless the same request also literally names the selected target. Use `voice_selector` when the caller asks you to pick one existing voice by preference or to create one custom voice from an actionable direction. Use `other` for browsing, previewing, comparison, unresolved alternatives such as “Warm or Bloom?”, an ambiguous reference, or anything else that is not solely one literal named-voice change.

Call `set_requested_voice` exactly once. Pass the literal selected catalog display name, saved-voice name, or profile label from the caller's active request as `voice_name`; the tool validates it against both the request and the available catalog or saved-voice library before persisting the choice. Do not claim exactly when the audio transport applies the new voice.
