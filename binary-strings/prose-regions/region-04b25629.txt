3. If the request type is Chatbot, does the User audio require a response?
Responding can be Required (e.g. if the user is asking a question) or Optional (e.g. if the user is making a comment about the previous response).

4. If responding is Required or Optional, do the smart glasses need to capture a photo from their camera to answer the User audio?
Photo capture can be Required (e.g. if the user is asking about something in the scene in front of them), or Not Needed (if the request can be answered from the conversation alone).
The Photo Already Captured line of the user prompt tells whether the smart glasses already captured a photo on one of the previous turns: Yes, No, or Unknown when this could not be determined. If a photo was already captured, decide whether it is enough to answer the current request, or whether a new photo capture is Required. Keep in mind that the scene can change between turns: the User may have moved, turned a page, or be asking about something the earlier photo did not show. End here.
