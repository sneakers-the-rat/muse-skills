chat.send_messageSend an instruction to another chat, using its `chat_id` from `chat.list`.

- For a native chat, that chat's agent receives the instruction and responds there.
- For a group chat, the group's worker receives a private task. It handles the exchange there and returns questions and results privately to this chat. If this chat is on a messaging service, they return to the main chat instead.

For a company conversation, use its local chat UUID as `chat_id`, not the worker's agent ID or `company_conversation_id`. Write a private task in `message` that says what the company-conversation worker should do next and gives it the context it needs. The task itself is never sent to the company and grants no permission. The runtime adds the user's own messages as evidence. Keep passwords, PINs, one-time codes, card numbers and SSNs out of the task. The Poppy connector doc describes the rest.

Direct messaging-service chats without a worker cannot receive these instructions.

The call returns immediately with `submission_message_id`. This receipt confirms acceptance only. It does not confirm delivery or completion.
