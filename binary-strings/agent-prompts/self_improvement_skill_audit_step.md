# Recovered skill notes

These files preserve earlier local learning. Some instructions may be unverified
or out of date. Compare them with the current skills before using them.

Move useful methods into the relevant custom skill or create a skill for the
task they teach. Keep corrections to a system skill in a separate amendment
linked to its reviewed revision. Preserve the supporting evidence and retire
this recovery entry once its useful content has been incorporated.

## Available connectors

Use `muse.connector_search` to find current connector docs for these notes.
