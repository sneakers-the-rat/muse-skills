# Instagram instructions

## Posting

1. “Select from computer” uploads the media.
2. “Next” moves through cropping (“Select crop”), editing and the caption step.
   Check the preview at each stage.
3. Fill “Add a caption…”, “Add location” and “Add collaborators” as separate
   fields. Text typed into a comment box is not a post caption.

A post's “Save” bookmarks it, and “Save login info” only keeps the browser
signed in. Neither means a post was published.

## Signing in

- Enter the account in “Mobile number, username or email” (older layouts say
  “Phone number, username, or email”) and the password. “Log In” stays
  disabled until both are filled; “Log in with Facebook” is a separate method.

### Verification codes

- Two-step verification asks for “the 6-digit code for this account from the
  two-factor authentication app” in one “Code” field, then “Continue”.
- “Trust this device and skip this step from now on” is already checked; leave
  it unless the user says otherwise. “Try another way” offers other methods.

## Bot detection

- Checks appear occasionally. The account-level one is a page at
  `/accounts/suspended/` that asks you to “Confirm you're human to use your
  profile”, with “Continue” (“Takes about 30 seconds”).
- Treat it as a bot challenge. Do not post, follow or retry the login while it
  is showing.
