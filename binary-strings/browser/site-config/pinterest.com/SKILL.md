# Pinterest instructions

## Page setup

- Close overlays that cover the page: “Close Bottom Right Upsell”, the
  signed-out prompt (“You are signed out”) and, in Pin creation, “Close drafts
  sidebar”.

## Browsing

- Search with the “Search” box and check the active filters (“Show filters”).
- A Pin's source link opens the original website; the Pin itself is not a store
  checkout.
- “Save” saves a Pin to a board. Check the selected board; saving never buys
  the pictured product.

## Creating Pins

- The Pin creation tool (`/pin-creation-tool/`) takes media through “File
  upload” or “Save from URL”, which are different inputs.
- Verify the preview, destination link and board before publishing. “Publish
  at a later date” schedules the Pin instead of posting it now.
- Unpublished drafts show how many days remain before they expire.

## Signing in

- The login form takes “Email” and “Password”, then “Log in”. Google and
  “Continue with QR code” are separate methods.

## Bot detection

- Bot checks are uncommon on Pinterest; the login form carries reCAPTCHA. If a
  check appears, treat it as a bot challenge and do not resubmit the form while
  it is showing.
