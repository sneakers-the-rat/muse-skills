# Greenhouse instructions

## Finding the job

- Open the employer's job board and the specific job; its page is titled “Job
  Application for <role> at <employer>”. Confirm the role and location before
  filling anything; one board can span many offices.
- Use “Apply” to reach the application form when the description and form are
  separate.

## Filling the application

- Choose the phone country separately from the number.
- Custom dropdowns need an observed option selected. Typed text left in their
  search field is not an answer.
- Education and work dates are separate month and year controls; “Add another”
  adds a row.
- Upload the requested résumé or cover letter and verify the attached file
  name. Selecting a file does not prove the upload finished.
- Answer work authorization and sponsorship questions only from supplied facts
  or the user's choices. For a voluntary demographic question the user left
  open, choose the option that declines to answer.

## Submitting

1. Press “Submit application” once and read the inline validation it returns.
2. If Greenhouse asks for an email verification code instead, enter it as
   described below. “Submit application” stays disabled until the code is in;
   press it once more only then.
3. The application is sent only when the confirmation page appears: “Thank you
   for applying”, at a URL ending in `/confirmation`.

A disabled submit button or a challenge is not an application receipt.

## Signing in

- MyGreenhouse (my.greenhouse.io) signs candidates in with an “Email” and
  “Send security code”, or with Google, Apple or LinkedIn. An employer's own
  Greenhouse account uses a separate sign-in.

### Verification codes

- After submission, Greenhouse can email a code (“A verification code was sent
  to … To submit your application, enter …”) and show eight single-character
  boxes. Only the first is labelled “Security code”; the other seven have no
  label. All eight are one verification-code field: supply their references in
  order, never the first box alone.

## Bot detection

- Greenhouse forms carry reCAPTCHA. It usually passes invisibly; a visible
  CAPTCHA at submission is a bot challenge.
- Never resubmit the application to get past a check.
