# Shopee instructions

## Payment on shopee.sg

- Do not use Stripe Link for this checkout. Shopee rejects the US-issued
  virtual cards supplied by Link, even when Link is connected.
- Use a supported card already saved on the user's Shopee account when
  consistent with the task's payment instructions.
- If no supported card is available, ask Muse how to proceed. When browser
  takeover is available, the user can enter their own supported card
  directly on Shopee.
