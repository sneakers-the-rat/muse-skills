# Yahoo! JAPAN instructions

## Page setup

- The homepage can open with a prompt to make Yahoo! JAPAN your start page
  (“今すぐ設定する”). Close it with “閉じる”.

## Searching

- Web search, Shopping and Auctions are separate services. Check the current
  host and selected service before reading a result or price.
- The homepage offers “ウェブで検索”, “AIモードで検索” and “画像で検索”. Use web
  search for ordinary results.
- “検索” or “検索する” runs the search. “検索条件を保存” saves the search
  conditions; it neither runs the search nor buys anything.

## Shopping checkout

- “ログインして注文” checks out with an account; “ログインせずに注文” is guest
  checkout when offered.
- “カートを空にする” empties the cart. Do not use it to close the cart view.

## Bot detection

- Bot checks and blocks appear fairly often on Yahoo! JAPAN. Treat a challenge
  page as a bot challenge.
- A connection reset (ERR_CONNECTION_RESET) is a network error, not a block or
  an empty result.
