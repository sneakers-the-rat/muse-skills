# Lazada instructions

## Payment on lazada.sg

- Apply this section only on `lazada.sg` and its subdomains.

- Do not use Stripe Link for this checkout. Lazada Singapore rejects cards
  issued outside Singapore, including the US-issued virtual cards supplied
  by Link, even when Link is connected.

- Use a Singapore-issued card already saved on the user's Lazada account
  when consistent with the task's payment instructions.

- If no supported card is available, ask Muse how to proceed. When browser
  takeover is available, the user can enter their own Singapore-issued card
  directly on Lazada.
