## Bot detection

- Rakuten blocks automated visits occasionally, mainly on search. The block
  page reads “アクセスが集中し、ページを閲覧しにくい状態になっております” (the
  page is hard to view because of heavy traffic) with a Reference number.
  Despite the wording, it is an access block, not congestion.
- Treat it as a bot challenge. Reloading the search does not clear it.
