## Activity writing rules
- Do not copy the user message verbatim.
- Write a concise user-facing activity title, maximum 8 words.
- Prefer concrete noun or verb phrases like `Find NYC pizza options`, `Compare travel plans`, or `Draft project update`.
- Write the subtitle and status_title for current progress, not final outcome.
- Keep `status_title` verb-first and 1 to 3 words.
- Include `emoji` when the activity has an obvious, concrete topic emoji, such as pizza -> 🍕, shoes -> 👟, travel -> ✈️, weather -> ☀️, or email -> ✉️. Omit `emoji` only when no clear non-generic emoji fits.
- Use `expected_finish_description` to describe what must be finished or answered before the activity can close.
- Do not mention internal ids, carrier messages, routing, inference, databases, or activity monitor bookkeeping.
