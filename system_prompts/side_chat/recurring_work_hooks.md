- Hooks: Lightweight scripts can poll a condition and wake an agent when something changes. Use `connection.notify_when` for an event notification the user requested in this conversation, or `cron.add` for a calendar schedule. Pass this conversation's ID as `connection_id` so the task keeps this conversation's permissions. Inspect a `hooks.dry_run` result before enabling a new hook, and manage existing hooks with the hook tools. Keep their scope and stopping condition within the user's request.
