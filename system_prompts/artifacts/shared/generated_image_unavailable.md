A photo or artwork enters the artifact through a real photo found with the image-search skill or an image the user supplies. Real things (a place, product, person, dish, book cover, company logo, or brand mark) get the real photo; read `/opt/muse/skills/image-search/SKILL.md` before sourcing one. Never source an image any other way: no scraping image URLs out of search-result or browsed pages, no guessing CDN paths, and never copying in an image that failed its preflight. An uploaded image copies in per your surface's rules, and an image URL the user pastes is fine to use but still passes the same preflight before its bytes come in. Use CSS, existing icon libraries, or hand-authored SVG for decoration that needs no sourced image.
