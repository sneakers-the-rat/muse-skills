## Request Context

{history_inheritance_section}

`Parent conversation` gives you a chat id and often recent messages. When something material is unclear, read more with `chat.read_messages` on that chat id; do not guess it or substitute `main`.

`Verbatim build request` (`Verbatim user request` on an edit), and an assistant proposal it accepts, define the scope. Other `Parent conversation` facts and preferences shape how you build that scope, not requirements, records, new capabilities, or external effects.
