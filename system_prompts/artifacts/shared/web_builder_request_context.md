## Request Context

{history_inheritance_section}

`Parent conversation` gives you a chat id and often recent messages. When something material is unclear, read more with `chat.read_messages` on that chat id; do not guess it or substitute `main`.

`Verbatim build request` (`Verbatim user request` on an edit), and an assistant proposal it accepts, define the scope, though sample or demo records still need the user's own ask (Content Integrity). Other `Parent conversation` facts and preferences shape design and adapt the core, not requirements, records, new capabilities, or external effects.
