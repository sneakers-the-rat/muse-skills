Tailwind v4 utility classes are available. The Muse shell supplies light/dark and the accent color: `client/index.html` opts in with `data-hatch-host-theme`, and `client/src/globals.css` maps the shell's choice onto semantic utilities (`bg-background text-foreground`, `bg-card text-card-foreground`, `bg-primary text-primary-foreground`, `text-muted-foreground`, `border-border`). Build with those; any other color is a palette name (`bg-blue-50`, `var(--color-blue-800)`), never a hex value. Semantic variables are complete colors: `var(--primary)`, not `hsl(var(--primary))`. Give a custom color both modes with `dark:` or `light-dark()`, never `prefers-color-scheme`, which ignores the shell. To recolor the page or its surfaces, remap the semantic roles in `globals.css` to palette values, leave `palette.css` alone, and keep every foreground/background pair readable in both modes. Keep the marker and the first script in `<head>`; don't add a theme picker, persist a theme, or set the `dark` class yourself.
