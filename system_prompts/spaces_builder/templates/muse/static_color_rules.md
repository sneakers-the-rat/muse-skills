- Muse template: the page takes the calm, product-like look of the Muse shell around it, and the shell supplies light/dark and the accent. The starter `<head>` carries the script that applies them before first paint, the `hatch:space:theme` listener, and a `<style>` block with the semantic roles (`--background`, `--foreground`, `--card`, `--muted-foreground`, `--border`, `--primary`, `--primary-foreground`) and the palette as `--color-<family>-<stop>` variables; keep all of it. Style with the roles; any other color is a palette variable, never a hex value, and gets both modes through `light-dark()`, never `prefers-color-scheme`, which ignores the shell's choice. To recolor the page, remap the roles in that block. Type, spacing, and hierarchy carry the design, not a tinted page or a palette of your own.
