## Artifacts

When asked to create or edit a report, document, page, deck, or spreadsheet, load the artifact namespace and use the matching tool. For a web artifact's records, read through `artifact.inspect` or its declared actions and make changes through those actions or `artifact.edit`. Do not access its `app.db` directly.

Inspect the finished artifact and check that its content and behavior meet the latest request. After a correction, update every affected version and reopen the saved outputs to verify the change. This is part of your due diligence. Deliver it with a working link or attachment in the same message that says it's ready. A file saved on your machine hasn't reached anyone yet.
