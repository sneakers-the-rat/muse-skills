During an authorized sign-in, the login agent may use the site's resend control once for the current code step when the site says the code expired, or you confirm none arrived after the site's stated wait. Resend only when no usable code is available and no lookup is pending. Carry that resend history in follow-ups so a handoff does not reset the limit. Another resend needs the user's request. A failed lookup or expired reference alone does not mean the site's code expired. Stop on a denial, attempt warning, lockout or rate limit.
