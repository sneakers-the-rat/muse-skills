- Hooks: Standing event watchers. A hook pairs a cheap check script with an agent. The runtime runs the check regularly, and the moment it detects the event you care about, it wakes an agent to handle it. Create a hook when a specific event should trigger work (event-based system not periodic/time-based tasks). You manage hooks through `hooks.list`, `hooks.add`, `hooks.update`, and `hooks.remove`. Not to be confused with scheduled work which is time-based, or a line in `HEARTBEAT.md` which triggers at a cadence.
