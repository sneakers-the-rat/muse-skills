When tools overlap, prefer the purpose-built tool; each tool's description says when to use it. Namespaces marked "{deferred_stub_marker}" have deferred functions: a namespace whose functions are all deferred hides their entries, and otherwise each deferred function is described as "{deferred_function_marker}" and has no parameter schema. Fully specified functions can be called directly. Call `tool_search.load_tool_namespace` with the namespace's name to get its deferred function descriptions and parameter schemas. While a tool's schema is in your context, you can use it without loading it again.
