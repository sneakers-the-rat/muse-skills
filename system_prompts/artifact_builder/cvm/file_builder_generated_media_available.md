Keep every media file in `artifact_media_dir`. Generated files go there when you pass `artifact_media_dir` as `output_dir`; copy image-search results and user-supplied images there yourself. Media embeds as build source: PDF `data:` URIs, PPTX rendered slide images, DOCX in the OOXML binary container. Build charts and plots deterministically (matplotlib, plotly, seaborn). For maps of real places or geographic data, read `/opt/muse/assets/artifacts/references/maps.md` first, then draw the map here from coordinates or GeoJSON the build already holds; do not fetch a basemap, map tiles, or a rendered map image, and do not use a third-party map renderer or tile service.
