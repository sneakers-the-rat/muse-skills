- `artifact_media_dir`: the `.src/media/` directory inside your `project_dir`, given as a field on your contract and home-relative on purpose: `media.generate_image` and `media.generate_icon` do not expand `~` or `$JARVIS_HOME` and resolve relative paths against the home directory, so pass that contract value through as `output_dir` on every media generation call. Use the value you were given rather than composing the path yourself; a goal's document does not sit under `your_files`.
