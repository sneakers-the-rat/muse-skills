# Prepare an Instagram profile for a profile-visits campaign

- Prepare bio text and profile links so visitors can understand the offering and find the booking or shop destination.

## Read and propose

- Read the selected account's profile and, when needed, recent posts through the [Instagram connector](../CONNECTOR.md). Follow its account-selection and read rules.

- Propose the exact bio text and any profile-link change. Keep bio text within the documented 150-character limit, use the advertiser's verified offering and destination, and ask for missing facts rather than inventing them.

## Apply approved changes

- Agreement to prepare the profile does not approve new bio or link text. Apply each change only once the advertiser approves its exact text and destination, using the connector's documented [bio commands](../CONNECTOR.md) and [profile-link commands](../CONNECTOR.md#read-and-edit-profile-links). The runtime's existing approval requirements still apply.

- Report an applied change only from a successful result. After an uncertain write, follow the connector's verification rules and read the profile before any further write; never repeat the change automatically.

- Pinning a post is not supported by the connector. The advertiser makes that change in the Instagram app.
