# Bing instructions

## Searching

- Use the search box or `/search?q=<encoded query>`. Open the actual result
  link; related searches and generated answers are not source documents.
- Use “Next page” for more results. Recheck the query after returning from a
  result, especially when the result opened in another tab.
- Advertisements, shopping cards and ordinary results are different. A price on
  a search card needs confirmation on the seller's current product page.

## Bot detection

- Bing frequently withholds results from automated searches. The page keeps
  its search box, the “Back to Bing search” heading and the filter row (“ALL”,
  “IMAGES”, “VIDEOS”), but lists no results, often with an empty page title.
  This is a block, not an empty result set: never conclude that something is
  unindexed or missing from it.
- Interactive checks also appear. Treat either as a bot challenge rather than
  rephrasing the query again and again.
