# Facebook media instructions

## Media links

- This host serves Facebook media, not the post's controls. Use the originating
  Facebook page for captions, context, comments and publishing.
- Keep observed media URLs intact. If an expiring URL stops working, refresh
  its source page for a new link instead of editing signed parameters.

## Bot detection

- Media requests are rarely blocked. When one fails, reload the source page,
  not the media URL.
