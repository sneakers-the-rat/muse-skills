# Qualtrics instructions

## Finding the right flow

- Surveys, the product site and the careers site are separate workflows, and
  their “Next” buttons advance different things. Identify which one the task
  needs before acting.

## Surveys

- Surveys run on organization hosts such as
  `<organization>.<region>.qualtrics.com/jfe/form/…`.
- Complete the visible required questions, press “Next”, then read validation
  messages and any newly displayed questions. Never invent answers.

## Careers

- Choose the location and role before “Apply now”; “Apply With LinkedIn” is a
  separate method.
- “Upload Resume” is done only when the attached file is confirmed.
- Leave the communications opt-in (“I agree that Qualtrics may send me
  communications…”) unchecked unless the user wants job emails.
- “Submit get notified for similar jobs” creates a job alert, not an
  application. Confirm the completion message for the action you were asked to
  take.
- Close the chat window with “Close Chatbot Window” if it covers the form.

## Bot detection

- Bot checks appear occasionally. Treat one as a bot challenge and do not
  resubmit the form while it is showing.
