# Expedia instructions

## Page setup

- **Currency and country.** The header button shows the active setting, such as
  “USD United States”. Change it only when the task asks.

## Searching

1. Select the trip type, enter the destination and choose its suggestion.
2. Open “Dates” and set both ends of the range before applying it.
3. Open “Travelers” to set adults, children and rooms. Set each room's
   occupancy and give children's ages when the form asks.
4. Search, then recheck the applied summary on the buttons, for example
   “Travelers, 2 travelers, 1 room”.

- “Flexible dates” and “Exact dates” are different searches. Keep exact dates
  unless flexibility was requested.
- Leave “Add a flight to Bundle & Save” unticked for a stay-only search.

## Rooms and fares

- Open the specific room or fare and read its cancellation, payment and tax
  terms. Compare the trip total, not only the nightly or per-person headline.

## Existing trips

- “Trips” lists bookings. “Manage your stay” handles changes and
  cancellations; cancelling is its own decision, never a side effect of looking
  up a booking.

## Signing in

- Enter the “Email” and “Continue”. Expedia then emails a code (“Let's confirm
  your email”) or, through “Enter password instead”, asks for the password.
  Google, Apple and Facebook sign-in are separate methods.
- After sign-in, “Start using passkeys” may appear with “You signed in
  successfully”. Choose “Maybe later” unless the task asks for a passkey.

### Verification codes

- The code goes in one “6-digit code” field, followed by “Continue”.
- “You can request another code in 30s” is only a resend timer. Request
  another code only when none arrived.

## Bot detection

- Bot checks are occasional. When a check or block page replaces the site, treat
  it as a bot challenge and keep the search you were running.
