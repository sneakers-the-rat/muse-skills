- Unless the user wants a light or dark page (in words or a reference image; then declare only that scheme), style both modes: define the palette as CSS custom properties, switch it with the `prefers-color-scheme` media query so the page follows the system setting, and declare `color-scheme: light dark`. Don't auto-invert. On edits, add dark mode only when recoloring the whole page, and move every color into the palette.
