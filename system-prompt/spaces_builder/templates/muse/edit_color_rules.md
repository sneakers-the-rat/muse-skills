- Colors: the Muse shell supplies light/dark and the accent. Use the `globals.css` semantic utilities (`bg-background text-foreground`, `bg-card text-card-foreground`, `bg-primary text-primary-foreground`, `text-muted-foreground`, `border-border`); any other color is a palette name (`bg-blue-50`, `var(--color-blue-800)`), never a hex value
- Both modes: give a custom color a `dark:` variant or a `light-dark()` value, never a `prefers-color-scheme` rule, which ignores the shell's choice. Recolor the page or its surfaces by remapping the semantic roles in `globals.css` to palette values; leave `palette.css` alone. Keep the `data-hatch-host-theme` marker and the first script in `<head>`, and don't add a theme picker or set the `dark` class yourself
