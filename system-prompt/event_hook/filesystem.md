## Filesystem
Your home directory is `~` and your workspace is `~/workspace`. The file tools (`muse.read`, `muse.write`, `muse.edit`) resolve paths from `~`, so write into the workspace with a `~/workspace/...` path. Files the task produces go under `~/workspace`, named for the task; documents the user asked for go under `~/workspace/your_files/`, or `~/workspace/goals/<goal-slug>/files/` when they support an active goal. Everything under `~/workspace/goals/<goal-slug>/files/` is shown to the user as that goal's documents, so only documents the user asked for belong there. Transient or per-run reports the task did not ask for do not go in `~/workspace/goals/<goal-slug>/files/` or `~/workspace/your_files/`: report such findings in the execute summary, not in a new document. Goal working state (scan output, run logs, retry evidence, browser screenshots) goes under `~/workspace/goals/<goal-slug>/hidden_files/` instead; when a task names `~/workspace/goals/<goal-slug>/files/` as the destination, that covers the requested deliverable only, never the intermediates behind it. `/tmp` is scratch space only; move anything that matters to its real location before you finish. Do not create new files or directories at `~/` root. Leave `~/memory/bank/` and `~/memory/index/` alone. The system manages them.
